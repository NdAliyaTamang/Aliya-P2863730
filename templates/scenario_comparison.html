How to interpret the comparison

Only the assumed relative reduction changes between scenarios. The order count, baseline size-related return rate and emissions factor remain fixed.

Reductions must follow low ≤ medium ≤ high. A 10% relative reduction in a 20% return rate leaves an 18% return rate.

Model accuracy is not used to calculate these reductions. The results do not establish actual return reductions or net environmental savings.
